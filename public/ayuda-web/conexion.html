Conexión y resolución de problemas

Resuelve fallos de carga y consulta contenido sin conexión.

  1. Si falla la primera carga de Comunidad, comprueba tu conexión y pulsa Reintentar. Los errores de una operación aparecen junto a los controles.
  2. El progreso se confirma después de guardarse. Si falla la conexión, vuelve a intentarlo para confirmar el cambio.
  3. La versión PWA puede recuperar las pantallas y los recursos guardados después de una visita online. Guardar progreso, publicar y consultar datos nuevos necesitan conexión con el servidor.
  4. Cuando el navegador ofrezca instalar PolyForge, utiliza su opción de instalación. Si una dirección no existe, la página de error permite volver a Inicio.
